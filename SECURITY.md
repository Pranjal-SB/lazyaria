# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it
privately: on the repository's Security tab, choose **Report a
vulnerability**. This opens a private security advisory that only the
maintainer can see.

Include what you found, the steps to reproduce it, and the version
(`lazyaria version`). You will get a reply in the advisory. Once a fix is
released, the advisory is published.
